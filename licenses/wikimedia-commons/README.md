# Wikimedia Commons

`icons/brand/` 里有一部分图形取自 Wikimedia Commons。它们在 Commons 上挂的是
**公有领域模板 + 商标标记**,所以这里没有许可证全文可抄 —— 只有模板的出处。

## 用了哪些文件

| 文件 | 许可模板 | 作者栏 | 用在哪 |
| --- | --- | --- | --- |
| [File:ChatGPT-Logo.svg](https://commons.wikimedia.org/wiki/File:ChatGPT-Logo.svg) | `PD-simple` | OpenAI | `icons/brand/chatgpt.svg` |
| [File:Grok logo without text.svg](https://commons.wikimedia.org/wiki/File:Grok_logo_without_text.svg) | 公有领域(标志) | xAI | `icons/brand/grok.svg` |

## 模板的意思

- [PD-simple](https://commons.wikimedia.org/wiki/Template:PD-simple) ——
  单纯的标志图形没有著作权(美国法),进公有领域。
- [PD-logo](https://commons.wikimedia.org/wiki/Template:PD-logo) ——
  标志的著作权可能过期或不存在,进公有领域。
- [Trademarked](https://commons.wikimedia.org/wiki/Template:Trademarked) ——
  挂上这个模板就是提醒:**公有领域说的是著作权,不是商标授权**。

这两个文件都带 `Trademarked`。商标那一层仍归 OpenAI / xAI 所有,
逐个的使用限制见 `brands/brand-chatgpt.md` 与 `brands/brand-grok.md`。
